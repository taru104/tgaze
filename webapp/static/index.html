tgaze は、Webカメラだけで視線の動きをリアルタイムに計測・可視化する Web アプリケーションです。

今すぐ体験する →
  • ◎リアルタイム推定
  • ⚙簡単セットアップ
  • 🛡この PC の中だけで動作
  • ▥データの記録・分析

使い方

  1. カメラ確認顔の位置と明るさをチェック
  2. キャリブレーション画面の9点を順番に見る（約30秒）
  3. 計測画面のどこを見ているかをリアルタイムに表示
  4. 分析注視点の分布・エリアごとの注視時間・CSV 書き出し

カメラと姿勢を確認しましょう

正確な視線推定のために、以下を確認してください。

  • 顔全体が映っている
  • 目がはっきり見えている
  • 正面を向いている
  • 明るい場所である

カメラの使用を許可してください。

キャリブレーションの手順

画面全体の9点を順番に見て、視線の基準を合わせます。
各点は数秒間表示され、自動的に次の点に進みます。

  1. 中央の点から開始します
  2. 点が表示されたら、その点を見続けてください
  3. 自動で次の点に進みます
  4. 9点で完了です
うまく計測するためのポイント
  • 画面から 40〜70cm の距離でご利用ください
  • 頭を大きく動かさず、リラックスしてください
  • できるだけ画面全体を使って行います
