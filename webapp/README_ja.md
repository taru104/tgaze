# tgaze Web アプリ（ローカル版）

`docs` のUIフロー図（①ランディング → ②カメラ確認 → ③説明 → ④全画面の案内 → ⑤9点キャリブレーション → ⑥完了 → ⑦リアルタイム計測 → ⑧結果分析）を、
この PC の中だけで動く Web アプリにしたものです。

## 起動

```bash
cd tgaze
.venv/bin/python webapp/server.py        # または: python webapp/server.py
```

ブラウザ（Chrome 推奨）で **http://localhost:8000** を開きます。カメラの使用を許可してください。
追加のインストールは不要です（サーバは Python 標準ライブラリ + tgaze が使う OpenCV / MediaPipe だけ）。

## しくみ

- ブラウザがカメラ映像を 640×480 の JPEG にして 1枚ずつ `server.py` に送り、サーバが `tgaze.GazeTracker`
  （16D幾何 + 目パッチ PCA16、既定のモデル）で推定して、画面上の位置 [0,1] を返します。1フレーム約 20〜30 ms。
- 映像・結果はこの PC の外には送りません（サーバは既定で 127.0.0.1 のみ待ち受け）。
- キャリブレーションは中央から始めて外周を時計回りに9点。1点あたり 0.8 秒待ってから 12 フレーム集めます。
- ⑥の「平均誤差」は leave-one-point-out 誤差です。cm への換算には③で選んだ画面サイズを、角度には 60 cm の距離を仮定しています。
- ⑦の計測対象はアプリ内のサンプルページです。`data-area` 属性の付いた要素がエリア分析の単位になります。
  ページをクリックすると、その位置を正解として視線のずれを補正します（`tracker.record_click`）。
- ⑧の注視（fixation）は I-DT 法（広がり 80 px 以内・100 ms 以上）。計測記録はブラウザの localStorage に保存され、CSV に書き出せます。

## 制限

- 1人用です（サーバは推定状態を1つだけ持ちます）。
- 計測を全画面にしないときは、ブラウザ枠の大きさから画面上の位置を推定するので、少しずれることがあります。全画面を推奨します。
- 動作確認は、合成画像を流す疑似カメラ + ヘッドレス Chrome で、全画面の流れ（①〜⑧）とエラーが出ないことだけを確かめています。
  実際の人のカメラでの精度は未確認です。
